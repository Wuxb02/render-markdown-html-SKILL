Reference Example 01

Document Review for Long Markdown Reports

A calm editorial layout for turning dense Markdown into a readable HTML document with navigation, summary cards, and explicit export controls.

At a glance
12 sections
4 controls
1 click save
2 formats
  • Summary
  • Findings
  • Actions

Summary

Markdown should remain the source of truth for structure, while HTML handles presentation, scanning, and interaction.

Controls

Any adjustable parameter should have a visible write-back button next to it, so editing never becomes a dead end.

Findings

  • Keep headings semantic.
  • Preserve links, lists, tables, and code blocks.
  • Use a compact toolbar for export and recovery actions.
This example is intentionally plain so later HTML generation can borrow its spacing, hierarchy, and control placement without inheriting unnecessary styling noise.
