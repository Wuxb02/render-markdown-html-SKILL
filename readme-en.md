# render-markdown-html

`render-markdown-html` is a skill for working with Markdown and HTML documents.

## What it does

- Renders Markdown into more readable HTML
- Turns parameterized HTML into an editable page
- Adds a clear `Write Back` button for configurable items
- Restores HTML into Markdown when Markdown is requested

## When to use it

- The user explicitly wants HTML output
- The user explicitly wants Markdown output
- The user wants to tune colors, spacing, or other parameters inside HTML
- The user wants a human-friendly view for a long document
